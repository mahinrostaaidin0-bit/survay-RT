=====================================================================
 SEO — چیکار کردم
=====================================================================
1) عنوان (title) و توضیح (meta description) مشخص و مرتبط با محتوا شد.
2) og:title / og:description / og:image / twitter:card اضافه شد تا
   وقتی لینک سایت رو تو واتس‌اپ، تلگرام، توییتر و... می‌فرستی، یه
   پیش‌نمایش درست (عکس+عنوان+توضیح) نشون بده.
3) داده ساخت‌یافته Schema.org (JSON-LD, نوع WebSite) اضافه شد تا
   گوگل بهتر بفهمه این صفحه چیه.
4) robots.txt و sitemap.xml ساخته شد (باید موقع هاست روی ریشه دامنه
   بذاریشون، نه داخل پوشه html).
5) favicon از همون svg لوگو ست شد.
6) alt متنی برای همه عکس‌ها از قبل وجود داشت (برای SEO تصاویر مهمه).

نکته مهم و صادقانه درباره سه‌زبانه بودن:
گوگل و موتورهای جستجو معمولاً هر زبان رو با یه URL جدا بهتر می‌شناسن
(مثلاً /fa/ و /en/ و /ar/ با تگ hreflang بین‌شون). این سایت چون همه
زبان‌ها رو با CSS تو یه صفحه سوییچ می‌کنه، گوگل هنگام ایندکس‌کردن
معمولاً فقط زبان پیش‌فرض (فارسی) رو می‌بینه. برای سئوی واقعی بین‌المللی
(که هر سه زبان جدا رتبه بگیرن)، بهترین راه اینه که در آینده سه صفحه
جدا (/fa/index.html، /en/index.html، /ar/index.html) با تگ‌های
hreflang به هم بسازیم. اگه خواستی این کارو هم برات انجام بدم بگو.

جاهایی که باید خودت عوض کنی قبل از هاست:
- همه‌ی "example.com" داخل index.html و robots.txt و sitemap.xml
  رو با دامنه واقعی سایتت جایگزین کن.

=====================================================================
 بک‌اند — خلاصه
=====================================================================
الان: پاسخ‌ها با جاوااسکریپت در localStorage همون مرورگر کاربر ذخیره
می‌شن. یعنی نیازی به سرور نداره و همین الان با باز کردن html/index.html
(یا هاست استاتیک) کار می‌کنه، ولی پاسخ افراد مختلف با هم جمع نمی‌شه.

برای جمع‌آوری واقعی و متمرکز پاسخ‌ها، فایل server/ کنار همین پوشه رو
ببین — یه بک‌اند نمونه با Node.js + Express + SQLite هست که:
- یه endpoint داره: POST /api/responses  (ثبت پاسخ)
- یه endpoint داره: GET  /api/responses   (خروجی JSON همه پاسخ‌ها، برای پنل ادمین)
- پاسخ‌ها رو در فایل survey.db (SQLite، بدون نیاز به نصب دیتابیس جدا) ذخیره می‌کنه

راه اجرا: داخل پوشه server دستور "npm install" بعد "npm start" رو بزن.
جزئیات کامل در server/README.txt هست.

=====================================================================
 آپدیت: SEO بین‌المللی (سه صفحه جدا با hreflang) — انجام شد
=====================================================================
ساختار جدید:
  public/
  ├─ index.html        (ریدایرکت خودکار به fa/)
  ├─ fa/index.html      (نسخه فارسی — زبان پیش‌فرض/اصلی)
  ├─ en/index.html      (نسخه انگلیسی)
  ├─ ar/index.html      (نسخه عربی)
  ├─ html/index.html    (نسخه‌ی قدیمی سه‌زبانه‌ی تک‌صفحه‌ای؛ فقط برای
  │                       پیش‌نمایش/تست محلی نگه داشته شده و noindex شده
  │                       تا با نسخه‌های fa/en/ar تداخل سئو نداشته باشه)
  ├─ css/ js/ img/ svg/ (مشترک بین هر سه زبان)
  └─ server/            (بک‌اند نمونه)

هر سه صفحه fa/en/ar:
- title و description مخصوص خودشون رو دارن (نه یه متن ثابت فارسی)
- <html lang="..." dir="..."> درست و واقعی دارن (نه فقط با CSS)
- به هم با تگ‌های hreflang وصل شدن تا گوگل بفهمه این سه تا ترجمه‌ی
  همدیگه‌ان، نه محتوای تکراری
- canonical مخصوص خودشون رو دارن
- سوییچ بالای سایت الان یه لینک ساده‌ست که آدم رو به پوشه‌ی زبان دیگه
  می‌بره (نه یه دکمه CSS که فقط ظاهر عوض کنه)

sitemap.xml هم آپدیت شد و هر سه آدرس رو با alternate‌های hreflang‌شون
لیست می‌کنه.

کاری که هنوز باید خودت انجام بدی:
- همه‌ی "example.com" رو (تو fa/en/ar/index.html و index.html و
  sitemap.xml و robots.txt) با دامنه واقعی سایتت عوض کن.
- بعد از هاست، توی Google Search Console سایت رو ثبت کن و sitemap.xml
  رو بهش معرفی کن تا گوگل سریع‌تر هر سه زبان رو بشناسه.
