این یه بک‌اند خیلی ساده و کامل‌کارکنه (نه فقط نمونه‌ی تئوری) هست که
می‌تونی همین الان اجرا کنی.

مرحله ۱ — نصب Node.js
اگه Node.js نصب نداری، از nodejs.org نسخه LTS رو نصب کن.

مرحله ۲ — نصب وابستگی‌ها
داخل همین پوشه (server) این دستور رو بزن:
    npm install

مرحله ۳ — اجرا
    npm start
اگه پیام "سرور بالا اومد: http://localhost:3000" رو دیدی، یعنی کار می‌کنه.

مرحله ۴ — وصل‌کردن سایت به این بک‌اند
داخل js/script.js، توی تابعی که روی دکمه «اتمام نظرسنجی» اجرا می‌شه، یک
خط fetch اضافه کن که پاسخ رو هم به این سرور بفرسته (علاوه بر localStorage):

    fetch('http://localhost:3000/api/responses', {
      method: 'POST',
      headers: {'Content-Type':'application/json'},
      body: JSON.stringify({device: detectDevice(), answers})
    });

مرحله ۵ — دیدن پاسخ‌ها
با مرورگر برو به:
    http://localhost:3000/api/responses
همه‌ی پاسخ‌های ثبت‌شده از هر کسی که فرم رو پر کرده، اینجا یک‌جا میان.

برای اینکه سایت واقعاً روی اینترنت در دسترس باشه (نه فقط روی
کامپیوتر خودت)، باید این پوشه‌ی server رو روی یک هاست که Node.js
اجرا می‌کنه (مثل Render، Railway یا یک VPS) بالا ببری و آدرس
localhost:3000 رو با آدرس واقعی همون سرور عوض کنی.
